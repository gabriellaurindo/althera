# Ritual System

The Ritual System is used to activate advanced mechanics in Althera, such as class progression and future summoning features.

To perform a ritual, you must build a specific structure around the Ritual Core.

---

## 🧱 Required Structure

The ritual is composed of **three vertical layers**, all centered on the Ritual Core.

---

### 🔹 Center

- Place the **Ritual Core** at the center of the structure

---

### 🔹 Layer 0 (Same Level as the Core)

- Place **4 Gold Blocks** around the core  
- They must form a **cross shape** (north, south, east, west)  
- All other positions must be **empty**

---

### 🔹 Layer +1 (Above the Core)

- Place **4 Netherrack blocks** in the same cross pattern  
- All other positions must be **empty**

---

### 🔹 Layer -1 (Below the Core)

- Place **1 Diamond Block** directly under the core  

⚠️ The Diamond Block will be **consumed** when the ritual is successfully activated.

## ⚠️ Validation Rules

For the ritual to work:

- All required blocks must be placed **exactly in the correct positions**  
- Any space that should be empty must **remain empty**  
- The structure must be properly centered on the Ritual Core  

If any part of the structure is incorrect, the ritual will fail.

---

## 🧠 Additional Notes

- This system is the foundation for future features such as:
  - Class changes  
  - Advanced summoning  
  - Hero progression  

More functionality will be added as development continues.
